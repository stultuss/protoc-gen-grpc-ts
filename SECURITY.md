# Security Policy

## Supported Versions

Security updates are provided for the latest published release on npm.

## Reporting a Vulnerability

Please report security vulnerabilities through the GitHub private
vulnerability reporting feature on the repository
(**Security** tab → **Report a vulnerability**). Do not open a public issue
for security problems.

Reports are acknowledged and triaged as soon as possible. Please include a
minimal description of the issue and, if possible, a reproduction.
